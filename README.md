# TRIADA music lab

Статический лендинг DJ-школы. Исходные фотографии сохранены в корне; оптимизированные версии — public/assets. Контент — index.html, оформление — src/style.css, поведение — src/main.ts. Шрифт Manrope поставляется локально через @fontsource (OFL).

## Локально

npm ci
npm run dev
npm test
npm run build

## GitHub Pages

Создать репозиторий, загрузить проект, выбрать Settings → Pages → Source: GitHub Actions. Workflow публикует ветку main. Относительные пути поддерживают /имя-репозитория/. Секретов в клиентском коде нет. Перед публикацией заменить относительный og:image абсолютным URL изображения на итоговом домене, добавить canonical и og:url с окончательным адресом сайта.

## Подключение заявок

1. Создать Telegram-бота через BotFather и закрытый чат команды; добавить бота, узнать ID чата.
2. В worker/wrangler.json установить ALLOWED_ORIGIN (только origin без пути репозитория).
3. Авторизоваться: npx wrangler login.
4. Сохранить токен интерактивно: npx wrangler secret put TELEGRAM_BOT_TOKEN --config worker/wrangler.json
5. Сохранить ID чата: npx wrangler secret put TELEGRAM_CHAT_ID --config worker/wrangler.json
6. Заменить проект текста в privacy-dialog в index.html реальными условиями обработки: ответственный и контакт, цели, перечень данных, используемые сервисы, срок хранения и порядок отзыва. Пока данных нет, отправка закрыта двумя независимыми флагами.
7. После готовности текста установить PRIVACY_READY в worker/wrangler.json в true (строка).
8. npx wrangler deploy --config worker/wrangler.json
9. В GitHub Settings → Secrets and variables → Actions → Variables добавить VITE_LEADS_ENDPOINT=https://ИМЯ-ОБРАБОТЧИКА.workers.dev/api/leads и VITE_PRIVACY_READY=true. Перезапустить workflow.
10. Выполнить настоящую тестовую заявку и проверить сообщение в закрытом чате, затем проверить доступность страницы и формы из Севастополя. Не считать локальные тесты подтверждением региональной доступности.

В разработке те же VITE-переменные можно задать в .env.local по .env.example; этот файл игнорируется Git. Токен никогда не помещать в VITE-переменные. Данные не пишутся в логи, отдельной БД нет. Хранятся сообщения в Telegram-чате; порядок удаления определяет команда. Ограничение: три попытки на IP за минуту, включая некорректные заявки. Повтор после сетевого сбоя может создать дубликат, если Telegram успел принять первое сообщение.

## Проверка

npm test — нормализация Telegram, поля, согласия, спам-поле, CORS, лимит запросов, отключённая конфигурация, ограничения тела запроса и ответы Telegram (mock).

npm run build — проверка TypeScript и статическая сборка.

npx wrangler deploy --dry-run --config worker/wrangler.json — проверка упаковки обработчика без публикации.

До подключения аккаунтов, данных ответственного и настоящего теста сайт работает как демонстрационная версия: форма не сообщает об успешной отправке и ничего не передаёт.

## Дизайн v2

Новые локальные шрифты: Unbounded Variable (заголовки) и Golos Text Variable (текст), оба с кириллицей. Оформление — src/premium.css. Canvas-свет, пауза и реакция логотипа на курсор — src/motion.ts. Кнопка «Движение» приостанавливает декоративные анимации; prefers-reduced-motion отключает их автоматически. При скрытой вкладке цикл и CSS-анимации приостановлены. На телефоне меньше частиц и узкая область света.

Четыре изображения сгенерированы встроенным imagegen, концептуальные (не фотографии школы): public/assets/equipment.webp, rhythm.webp, vinyl.webp, club.webp. Промпты сохранены в design/image-prompts.md. Исходные фото основателей и оригинальный логотип сохранены без изменений.

## P1: защита запуска

Форма изначально отключена в HTML (fieldset disabled, кнопка type=button). Даже если JavaScript не загрузится, посетитель не сможет отправить введённые данные через GET. Обработчик подключается до включения формы. Декоративная анимация загружается независимо.

Пока Telegram-бот и Worker не созданы, на сайте доступна прямая ссылка https://t.me/vgtksl. Ответственный: Кисляков Владимир Валерьевич. Срок хранения и порядок отзыва ещё необходимо согласовать. Форма остаётся выключенной.

Перед включением VITE_PRIVACY_READY=true завершить текст privacy-dialog (включая срок хранения, порядок отзыва, реальные сервисы), удалить предупреждение о черновике и заменить data-privacy-status="draft" на "ready". Vite отклоняет включение при незавершённом тексте или некорректном HTTPS endpoint /api/leads. Это проверка известных заглушек, а не юридическая экспертиза текста.

Сбой первого deploy произошёл на actions/configure-pages, после успешных тестов и сборки. Владельцу необходимо открыть Settings → Pages → Build and deployment → Source → GitHub Actions, затем повторить workflow. Текущий GitHub-коннектор не управляет настройками Pages.

Pull request запускает тесты и демосборку без публикации. После подключения реального обработчика отдельно проверить доставку тестовой заявки с разрешения владельца.

## Музыка на карточке «За пультом»

Присланный MP3 — public/assets/acid-dj.mp3. Управление — src/equipment-audio.ts: запуск только по нажатию пользователя, первое воспроизведение с предварительной позиции 55 секунд. Поле «Начать с, сек» позволяет уточнить начало фрагмента; после паузы воспроизведение продолжается с текущей позиции. Джог синхронизирован с событиями audio play/pause/ended. При скрытии вкладки или глобальной паузе анимации звук останавливается. Точное начало припева пока не подтверждено.
